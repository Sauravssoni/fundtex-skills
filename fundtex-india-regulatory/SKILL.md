# Fundtex India Regulatory Desk

Start with fundtex sources. For an authorized network run fundtex regulatory --feed sebi or --feed rbi-releases. For offline use, fundtex regulatory --file /approved/feed.xml.

Never treat RSS titles as independently verified legal changes. Open original linked published documents, note publication time and effective date, then provide applicable entity/sector, changes, downside/bull countercase and links actually inspected. Validate data rights; no unofficial NSE/BSE scraping or licensed quote redistribution. On denied network or malformed XML, return partial research with NOT VERIFIED status. Use source specialist and skeptic agents only when host tools and permissions permit, otherwise sequential review. No trading.
