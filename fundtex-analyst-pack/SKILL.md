# Fundtex Analyst Pack
Use fundtex analyst-pack --csv /approved/prices.csv --symbol INFY.NS --out /new/report-folder. Add --annotations, --holdings and --portfolio-prices only with user-approved data. Report output includes source hash, as-of date, research-only historical signals, interactive chart, visuals, memo and CSVs. Never overwrite an existing report folder. Optional Excel/PDF/browser outputs may be missing; inspect the manifest and disclose each omission instead of claiming success. For real analyst decisions verify the underlying dated NSE/BSE/issuer filings and give the strongest opposing thesis. No trades, no hidden file access, no live prices without an authorized provider.

## Report contract

- Include executive observation, dated price inputs, annotations, opposing market hypotheses and an unknowns section.
- Confirm the actual output folder contains every claimed file, and optional misses are listed in manifest.json.
- Treat issuer filings as verified only when the agent actually opened the original issuer or exchange document.
- No confidential employer or customer portfolios go to unapproved agents.
